# Shared firmware code

This directory holds reusable modules across ESP32-S3 board trials. The base `AQCommon` library in `src/` has no board pins, M5Unified calls, card mount policy, RTC driver, power, display, modem or radio initialization. The opt-in `runtime/` library holds settings/logging under its own AGENTS.md. The opt-in `connectivity/` library owns BLE/Wi-Fi transports under its own AGENTS.md. The board trial owns hardware adapters, sampling, measurement schema/version and the storage worker.

- Keep the Plantower byte framing and checksum here. Choose the sensor model explicitly at construction: PMSA003 and PMS5003T have the same 32-byte envelope, but different meanings at bytes 24–27. Never publish the PMS5003T's temperature/RH words as >5/>10 µm particle counts.
- Keep the bounded Parquet writer and LZ4 adapter here. Preserve `vendor/lz4` bytes and license; the adapter is tested with sanitizers and two readers via `pixi run parquet-test --sanitize`.
- A trial consumes the base library through Arduino CLI `--library firmware/common`; it can opt into `--library firmware/common/runtime` and `--library firmware/common/connectivity`. Never include a sibling trial. New board trials pass their own `created_by` to the writer; the default is the historical CoreS3 identity. Schema identifiers and provenance remain trial-owned; do not change existing file identities as a side effect of a repository rename.
- Numeric rows, UTC arithmetic and sync wire/path/checksum helpers are pure C++ and tested on the host. Keep clock locking, captured-row field mapping and RTC access in the consuming runtime; never invent an anchor or silently rewrite old rows.
- Device settings retain their NVS namespace and security behavior. `DebugLog` can borrow a board-selected `Print` sink, set before tasks start. Shared sensor register drivers borrow IO/timing callbacks and never initialize the controller.
- Board-specific validation belongs in that trial's README and its board's docs. A host fixture is not a real SD or power-loss test.
